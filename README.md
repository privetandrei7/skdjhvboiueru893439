# MARI — единая экосистема для марийцев

Первый Android-клиент экосистемы MARI.

## Первый этап

- Главная
- Мессенджер
- Карта
- Марийский язык
- Фольклор
- Маркет
- Услуги
- Генеалогия
- События
- Молодёжь
- MARI Mail
- Профиль

## Запуск

```bash
npm install
npx expo start
```

Для Android:

```bash
npm run android
```
